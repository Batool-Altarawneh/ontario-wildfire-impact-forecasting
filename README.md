# ontario-wildfire-impact-forecasting
An academic data analytics project examining Ontario wildfire activity, air quality impacts, and next-day AQHI forecasting.

## Project Planning

This project was scoped and planned before any code was written. Planning documents live in [`/docs`](./docs):

- [`project_charter.md`](./docs/project_charter.md): problem statement, goals, non-goals, constraints
- [`product_backlog.md`](./docs/product_backlog.md): epics, user stories, tasks, Definition of Done
- [`project_phase_plan.docx`](./docs/project_phase_plan.docx): phase-by-phase explanation, tools, techniques
- [`gantt_chart.xlsx`](./docs/gantt_chart.xlsx): sprint timeline

Work was run in Agile sprints, tracked in Jira, with GitHub commits linked to Jira tickets.
